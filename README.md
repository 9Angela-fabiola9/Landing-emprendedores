# Landing Page para Emprendedores - Impulsa tu Idea

Proyecto desarrollado como parte de la AHD3 y AHD4 del curso de Frontend.

## Requerimientos

### Requerimientos funcionales
- Mostrar información para emprendedores.
- Permitir navegar entre las diferentes secciones.
- Mostrar preguntas frecuentes.
- Adaptarse a dispositivos móviles mediante un menú responsive.

### Requerimientos no funcionales
- Interfaz clara y amigable.
- Código organizado.
- Uso de Git y GitHub.
- Migración a TypeScript.
- Aplicación de Programación Orientada a Objetos.

## Estructura del sitio
- Inicio
- Nosotros
- Beneficios
- Recursos
- Testimonios
- Preguntas frecuentes
- Footer

## Tecnologías
- HTML5
- CSS3
- Sass
- JavaScript
